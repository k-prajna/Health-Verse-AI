HealthVerse AI - Install on Windows
====================================

1. DELETE your old folder:
   C:\Users\PRAJNA\Desktop\healthverse-ai

2. Extract THIS zip to Desktop so you get:
   C:\Users\PRAJNA\Desktop\healthverse-ai\

3. Double-click START.bat
   OR in PowerShell:
   cd C:\Users\PRAJNA\Desktop\healthverse-ai\backend
   python main.py

4. Open browser: http://localhost:8000
   (Do NOT open index.html by double-click)

Demo login: demo@healthverse.ai / demo123

ENABLE REAL GOOGLE SIGN-IN
--------------------------
1. https://console.cloud.google.com/ → Credentials → Create OAuth client ID
2. Type: Web application
3. Origins: http://localhost:8000  and  http://localhost:8080
4. Copy Client ID
5. Paste into:
   - js/app.js          →  const GOOGLE_CLIENT_ID = "YOUR_ID";
   - backend/auth.py    →  GOOGLE_CLIENT_ID = "YOUR_ID"
6. Restart backend and refresh browser
